I built a complete multi-page college club website for MJPRU Coding Club with four pages. I created index.html as the home page showing club introduction, activities, and an events schedule table with <thead>, <tbody>, and <tfoot>. I built about.html to provide detailed club information, mission, and a members table with roles. I created registration.html with a full student registration form including text, email, tel, radio buttons, checkboxes, select dropdowns, textarea, and a disabled application ID field. I built contact.html showing email, phone number, location, meeting time, and social links with a quick contact form. I maintained consistent navigation across all pages using the same <nav> structure so users can easily switch between pages. I added proper metadata including UTF-8 encoding, viewport meta tag, meaningful titles, and meta descriptions, plus a favicon on all pages. I verified and tested all internal links to ensure smooth navigation throughout the website.
